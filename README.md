# 💍 Matrimonial Website

A modern matrimonial web application developed using Java, JSP, JDBC, MySQL, HTML, CSS, JavaScript, and Bootstrap. The project enables users to register, create and manage profiles, search for suitable matches, send interest requests, and communicate through an internal messaging system after mutual acceptance.

> 🚧 This project is actively under development, and new features are being added regularly.

---

## ✨ Current Features

### 👤 User Management
- User Registration
- Secure User Login & Logout
- Session & Cookie Management

### 📝 Profile Management
- Create Profile
- Update Profile Information
- Upload Profile Photo
- View Own Profile
- View Other User Profiles

### 🔍 Search System
- Search Registered Users
- View Detailed User Profiles

### ❤️ Interest Request System
- Send Interest Requests
- Accept Requests
- Reject Requests
- Pending Request Management

### 💬 Messaging System
- One-to-One Messaging
- Inbox
- Conversation Page
- Send Messages
- Delete Messages

### 🖼 Gallery
- Upload Multiple Gallery Images
- Display User Gallery
