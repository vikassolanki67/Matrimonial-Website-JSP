# 💍 Matrimonial Website

A full-stack matrimonial website developed using Java, JSP, JDBC, MySQL, HTML, CSS, JavaScript, and Bootstrap.

## Features

- User Registration
- User Login
- User Profile
- Profile Update
- Search Profiles
- Interest Request System
- Inbox
- Internal Messaging
- Gallery Upload

## Tech Stack

- Java
- JSP
- JDBC
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
